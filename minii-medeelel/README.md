# Миний мэдээлэл AI: e-Mongolia PoC

Хэрэглэгч e-Mongolia-д нэвтэрсний дараа extension түүний төрийн мэдээллийг нэг дор татна. Үүнд эрүүл мэндийн даатгал, НДШ, торгууль, нэхэмжлэх, зээл, тээврийн хэрэгсэл, бичиг баримтын хугацаа зэрэг орно. Дараа нь:

1. **Өмнөх сартай харьцуулна.** Юу нэмэгдсэн, хасагдсан, өөрчлөгдсөнийг кодоор олж жагсаана. Энэ хэсэгт AI оролцохгүй.
2. **AI-аар хураангуйлна.** Жишээ нь: «2 хоногийн өмнө 100,000₮-ийн торгууль үүссэн, хурдан төлөөрэй», «9-р сарын ЭМД төлөгдөөгүй», «Паспорт 40 хоногийн дараа дуусна».

## Урсгал

```
e-Mongolia таб (нэвтэрсэн)
  └─ content.js: /api/routes/xyp-ийг хэрэглэгчийн өөрийн token-оор дуудна (ХУР-ын 10 сервис)
side panel
  ├─ lib.js redact(): РД, нэр, хаяг, утас, зураг… хасна; улсын дугаарыг ****УБА болгоно
  ├─ сар бүрийн агшинг chrome.storage.local-д хадгална (13 сар хүртэл, зөвхөн энэ компьютерт)
  ├─ lib.js diff(): өмнөх сарын агшинтай харьцуулж ялгаа гаргана
  └─ «AI-аар хураангуйлах» дарахад: нууцалсан өгөгдөл ба ялгааг сонгосон AI руу илгээнэ
       Gemini (үнэгүй) / Claude / Worker → { headline, alerts[], changes[], ok[] } JSON
extension/ai.js: нэгдсэн prompt + JSON schema
worker/ (Cloudflare, Claude): /summarize — бусдад тараах үед key-г серверт хадгална
```

## Мэдээллийн эх сурвалж

Эдгээрийг e-Mongolia сайтын JS-ээс олсон. «Миний мэдээлэл» хэсэг ХУР-ын эдгээр сервисийг дууддаг. Жагсаалт нь [extension/sources.js](extension/sources.js)-д байна:

| Мэдээлэл | ХУР сервис |
|---|---|
| Эрүүл мэндийн даатгал | `WS300101_getInsuranceFee` |
| НДШ | `WS100501_getCitizenSalaryInfo` |
| Тээврийн хэрэгслийн торгууль | `WS100403_getVehiclePenaltyList` |
| Төлөгдөөгүй нэхэмжлэх | `WS100439_unpaidInvoiceInfo` |
| Зээл | `WS100831_citizenLoanInfo` |
| Тээврийн хэрэгсэл | `WS100406_getCitizenVehicleList` |
| Албан журмын даатгал | `WS100458_MandatoryInsuranceShortList` |
| Иргэний үнэмлэх | `WS100101_getCitizenIDCardInfo` |
| Гадаад паспорт | `WS100110_passportInfo` |
| Үл хөдлөх хөрөнгө | `WS100202_getPropertyList` |

Хүсэлтийн хэлбэр: `POST /api/routes/xyp`, header нь `X-Auth-Token: <auth-token cookie>`, body нь `{ "target": "xyp-data", "params": { "serviceCode": "...", "sid": null } }`.

**Анхаарах:** эдгээр сервисийг бодит нэвтэрсэн session дээр хараахан туршаагүй. Зарим нь нэмэлт параметр (жишээ нь улсын дугаар) шаардаж магадгүй. Side panel-д сервис бүрийн ✓ / ✗ төлөв харагдана.

## Ажиллуулах

**Extension**
1. `chrome://extensions` руу орж Developer mode-ыг асаана. **Load unpacked** дарж `minii-medeelel/extension` хавтсыг сонгоно.
2. e-Mongolia-д ДАН-аар нэвтэрнэ. Extension-ий дүрс дээр дарж **Шинэчлэх** дарна.

**AI хураангуй: Google Gemini (үнэгүй, анхны тохиргоо)**
1. https://aistudio.google.com руу Google бүртгэлээрээ нэвтэрнэ. **Get API key** → **Create API key** дарж `AIza…` хэлбэрийн key авна. Карт шаардахгүй.
2. Side panel-ийн **Тохиргоо** хэсэгт «Google Gemini (үнэгүй)» сонгогдсон эсэхийг шалгаад key-ээ буулгаж Enter дарна.
3. **AI-аар хураангуйлах** дарна. `gemini-3.8-flash` загвар ашиглана.

> ⚠️ Gemini-ийн үнэгүй хувилбарт Google илгээсэн мэдээллийг бүтээгдэхүүнээ сайжруулахад ашиглаж, хүн уншиж магадгүй ([үнийн хуудас](https://ai.google.dev/gemini-api/docs/pricing)). Extension нэр, РД, хаяг, төрсөн огноог хасдаг ч даатгал, зээл, хөрөнгийн мэдээлэл очно. Үүнийг хүсэхгүй бол Claude (төлбөртэй) эсвэл төлбөртэй Gemini key ашиглана.

**Claude (төлбөртэй):** Тохиргоонд «Claude» сонгоод console.anthropic.com-ийн key-ээ оруулна. Загвар нь Claude Opus 5.5, нэг хураангуй хэдэн центийн зардалтай.

**Бусдад тараах үед: Cloudflare Worker (заавал биш)**

Ингэвэл API key хэрэглэгчийн компьютерт биш, серверт хадгалагдана.
```bash
cd minii-medeelel/worker
npm install
npx wrangler login
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put APP_TOKEN
npx wrangler deploy
```
Тохиргоо → «Эсвэл Cloudflare Worker ашиглах» хэсэгт URL болон `APP_TOKEN`-оо оруулна. API key талбарыг хоосон үлдээнэ.

AI-ийн логик (prompt, JSON schema, загвар) нь [extension/ai.js](extension/ai.js)-д байгаа бөгөөд хоёр горим хоёулаа үүнийг ашигладаг. `extension/vendor/anthropic.js` нь албан ёсны `@anthropic-ai/sdk`-ийг esbuild-ээр bundle хийсэн файл:
```bash
cd minii-medeelel/worker && echo 'export { default } from "@anthropic-ai/sdk";' > e.mjs && npx esbuild e.mjs --bundle --format=esm --platform=browser --minify --outfile=../extension/vendor/anthropic.js && rm e.mjs
```

## Нууцлал

- Өгөгдлийг хэрэглэгчийн компьютер дээр **нууцалсны дараа** хадгална. Хадгалахаас өмнө РД, нэр, хаяг, утас, имэйл, зураг, карт болон дансны дугаарыг хасна.
- AI руу зөвхөн «AI-аар хураангуйлах» дарсан үед илгээнэ. Юу илгээхийг side panel-ийн «AI руу юу илгээхийг харах» хэсгээс урьдчилан харж болно.
- Нууцалсан ч торгуулийн дүн, даатгалын төлөв, зээлийн үлдэгдэл мэт **хувийн санхүүгийн мэдээлэл AI руу очно**. Бүтээгдэхүүн болгохдоо хэрэглэгчээс тодорхой зөвшөөрөл авах хэрэгтэй.
- ХУР-ын сервис бүрийг дуудах үйлдэл иргэний «мэдээлэл хандалтын түүх»-д бүртгэгдэж болно. Иргэн өөрөө өөрийн мэдээлэлд хандаж байгаа тул энэ нь хэвийн.
