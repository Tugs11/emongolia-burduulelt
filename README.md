# Миний мэдээлэл AI — e-Mongolia PoC

Нэг Chrome extension. Хэрэглэгч e-Mongolia-д ДАН-аар өөрөө нэвтэрсний дараа:

1. **Шинжлэх**: ЭМД, НДШ, нэхэмжлэх, зээл, тээврийн хэрэгсэл, торгууль, оношилгоо, бичиг баримт, хөрөнгийн мэдээллийг ХУР-аас татаж **AI-аар хураангуйлна**. Жишээ нь: «Паспорт 43 хоногийн дараа дуусна», «9-р сарын НДШ төлөгдөөгүй».
2. **Асуулт асуух**: «Миний цэргийн алба хаасан мэдээлэл хэр байна?» гэх мэт. Татсан мэдээлэлд байгаа зүйлд шууд хариулна. Байхгүй бол «татагдаагүй» гэж хэлээд e-Mongolia-ийн тохирох үйлчилгээг холбоостой нь санал болгоно.
3. **Бичиг баримт бүрдүүлэх**, хоёр замаар:
   - **Зорилгоор (chat):** «Солонгос руу жуулчны виз мэдүүлэх бичиг баримт бүрдүүлэх» гэж бичихэд AI шаардлагатай жагсаалт гаргана.
   - **Жагсаалтаар (таб):** банк, сургууль, элчин сайдын яамнаас өгсөн жагсаалтаа текстээр эсвэл **зургаар** оруулна. AI мөр бүрийг задалж e-Mongolia-ийн үйлчилгээтэй тааруулна.

   Аль алинд нь **Цуглуулах** дарахад e-Mongolia-оос лавлагаануудыг PDF-ээр татаж, **нэг ZIP багц** болгоно: `Downloads/Burduulelt/<зорилго>_<огноо>.zip`. Багцад PDF бүр болон `Жагсаалт.txt` (өөрөө бэлдэх зүйлс, зөвлөмж) орно.

Таб бүрт **↺ Дахин эхлүүлэх** товч байна. Энэ нь тухайн табын хураангуй, chat эсвэл жагсаалтыг цэвэрлэж шинээр эхлүүлнэ. Сар бүрийн агшин (snapshot) устахгүй.

Хэрэглэгч ямар нэг тохиргоо, API key оруулахгүй. AI-г төслийн сервис ([worker/](worker/)) дуудна.

> Өмнө нь энэ repo-д хоёр тусдаа extension байсан: «Бүрдүүлэлт AI» (`extension/`, жагсаалтаар PDF татах) ба «Миний мэдээлэл AI» (`minii-medeelel/extension/`). 2026-10-08-нд хоёуланг нь нэг extension болгож `extension/`-д нэгтгэсэн. Хоёр AI сервисийг мөн `worker/`-д нэгтгэсэн. `minii-medeelel/` хавтас repo-оос хасагдсан. Өмнө нь `minii-medeelel/extension`-ийг суулгасан бол `chrome://extensions` дээрээс **Remove** хийгээд доорх ZIP-ийг суулгана.

## Татаж суулгах

**[⬇ minii-medeelel-ai.zip татах](https://github.com/Tugs11/emongolia-burduulelt/releases/latest/download/minii-medeelel-ai.zip)**

1. ZIP-ийг задална (Windows: баруун товч → **Extract All**).
2. Chrome-ийн хаягийн мөрөнд `chrome://extensions` гэж бичээд баруун дээд буланд байгаа **Developer mode**-ыг асаана.
3. **Load unpacked** дарж задалсан хавтсыг (`manifest.json` байгаа) сонгоно.
4. 🧩 дүрс → **Миний мэдээлэл AI**-г 📌 pin хийнэ. Дүрсэн дээр дарахад баруун талд side panel нээгдэнэ.

ZIP-ийг GitHub Actions ([.github/workflows/extension.yml](.github/workflows/extension.yml)) `extension/` өөрчлөгдөх бүрт автоматаар шинэчилдэг. Тиймээс дээрх холбоос үргэлж хамгийн сүүлийн хувилбарыг татна. Дэлгэрэнгүй заавар: [ZAAVAR.md](ZAAVAR.md).

## Урсгал

```
e-Mongolia таб (нэвтэрсэн)
  └─ content.js: /api/routes/xyp-ийг хэрэглэгчийн token-оор дуудна (11 эх сурвалж)
side panel
  ├─ «Миний мэдээлэл» таб
  │    ├─ lib.js redact(): РД, нэр, хаяг, утас, зураг, паспорт/машины дугаар… хасна
  │    ├─ сар бүрийн агшинг chrome.storage.local-д хадгална, өмнөх сартай diff()
  │    ├─ POST /summarize → { headline, alerts[], changes[], ok[] }
  │    └─ chat: POST /chat { question, history, data, summary, services } → { answer, services[], intent, purpose }
  │             intent=documents → POST /plan { purpose, emongoliaServices } → { title, addressee, language, addresseeForeign, items[], tips[] }
  ├─ «Жагсаалтаар бүрдүүлэх» таб
  │    └─ POST /parse { text | image, emongoliaServices } → /plan-тай ижил хэлбэр
  │       AI ажиллахгүй бол catalog.js localPlan(): түлхүүр үгээр задална (зураг уншихгүй)
  └─ хоёуланд нь: catalog.js matchService() → эргэлзээтэй бол хэрэглэгч сонгоно (сонголтыг санана)
       → background.js COLLECT_DOC → collector.js (маягт бөглөх, PDF) → zip.js → нэг ZIP
       (AI зөвхөн өгсөн нэрсээс сонгоно, холбоосыг extension үүсгэнэ)
worker/ (Cloudflare): src/ai.js — prompt + JSON schema, Gemini (давуу) эсвэл Claude
```

### Үйлчилгээ тааруулах

e-Mongolia-ийн хайлт үгийг бүтнээр нь, бүх үгийг заавал тааруулдаг: «үнэмлэх**ний**» → 0 илэрц, «үнэмлэх**ийн**» → олдоно. Тиймээс сайтын хайлтыг ашиглахгүй. Бүх үйлчилгээний жагсаалтыг (`content/search?pageSize=5000`, ~1,460) өдөрт нэг удаа татаж, [extension/catalog.js](extension/catalog.js)-д тааруулна:

- Нөхцөлийн дагавар өөр байсан ч нэг үг гэж үзнэ («үнэмлэхний» = «үнэмлэхийн», «даатгалын» = «даатгал»). Үүнд trigram ижил төстэй байдлыг нэмж эрэмбэлнэ.
- «хуулбар», «тодорхойлолт», «лавлагаа» мэт үгс албан нэрэнд өөрөөр бичигдсэн байсан ч тааруулна.
- «(гадаад хэлээр)» хувилбар, «хүсэлт», «захиалах», «төлөх» зэрэг лавлагаа биш үйлчилгээг сүүлд эрэмбэлнэ.
- Эргэлзээтэй үед таамаглахгүй, шилдэг 6-г харуулж хэрэглэгчээр сонгуулна. Сонголтыг `learned`-д санана.

### Цуглуулах (collector.js)

| Алхам | Тайлбар |
|---|---|
| Аюулгүй байдлын шалгалт | «Төлбөр: Үнэгүй», «Хугацаа: Шууд» биш бол автоматаар үргэлжлүүлэхгүй. «Хуудсыг нээх» товч санал болгоно. |
| «Үйлчилгээ авах» | Цэсэнд мөн ижил нэртэй, `/service` руу хөтөлдөг товч байгаа тул `nav/aside/header` доторхыг алгасна. Хуудас ачаалахад нээгддэг «Видео заавар» modal-ыг хаана. |
| «Тодруулга» | Өмнө авсан бол «Шинээр авах» дарна (үнэгүй, шууд гардаг үйлчилгээнд л). «Таны мэдээлэл бүртгэлгүй байна» → `NOT_REGISTERED`. |
| Маягт (`/apply`) | «Эхлэх он / Дуусах он» (AI тооцсон `years`), «Хаана зориулж» (`addressee`, эсвэл маягтын жишээ текст), «Ү дугаар» (ХУР-аас), хүн сонгох radio, «Өөртөө / Хүүхдийн» (`subject`). Танихгүй шаардлагатай талбар байвал бөглөхгүй, «маягтыг өөрөө бөглөнө» гэж зогсоно. |
| «Хэл сонгох» | «(гадаад хэлээр)» лавлагаанд. AI зорилгоос нь хэлийг (`language`) сонгоно: ихэнх элчин сайдын яамд англи хэлийг хүлээн авдаг тул анхдагч нь англи, ОХУ бол орос. Хэрэглэгч жагсаалт дээрээс сольж болно. Тухайн хэл маягтад байхгүй бол англи, ганц сонголттой бол түүнийг сонгоно. Ant Design Select, radio, checkbox бүгдийг дэмжинэ. «Хаана зориулж»-д тэр хэлээрх хаягийг (`addresseeForeign`) бичнэ. |
| PDF | Шууд гардаг лавлагаа `/service/{id}/apply` хуудсанд **blob: iframe**-д гарна. Content script blob-ийг уншиж (`%PDF-` эсэхийг шалгаад) data URL болгоно. Side panel бүгдийг нэг ZIP болгож татна. |

## Бичиг баримт цуглуулах туршилт (2026-10-08, бодит бүртгэл дээр)

5 зорилгоор туршсан: ипотекийн зээл, ажилд орох, төрийн албаны шалгалт, хүүхдээ сургуульд бүртгүүлэх, тэтгэвэр тогтоолгох. Chat бүгдийг `documents` гэж таньж, жагсаалт гаргасан. Жагсаалтад орсон e-Mongolia-ийн 12 үйлчилгээг нэг бүрчлэн туршсан:

| Үйлчилгээ | Маягт | Үр дүн |
|---|---|---|
| Иргэний үнэмлэхийн лавлагаа | — («Тодруулга» → Шинээр авах) | ✓ PDF |
| НДШ төлөлтийн лавлагаа | Эхлэх он, Дуусах он, Хаана зориулж | ✓ PDF |
| Хаягийн лавлагаа | Хаана зориулж | ✓ PDF |
| Гэрлэсний бүртгэлийн лавлагаа | — | «бүртгэлгүй» → **Гэрлэсний бүртгэлгүй лавлагаа** руу шилжинэ ✓ PDF |
| Үл хөдлөх хөрөнгийн лавлагаа | Ү дугаар (ХУР-аас, эх «у» үсэгтэй нь) | ✓ PDF |
| Эрүүгийн хариуцлага (байсан / байгаа эсэх) | хүн сонгох radio (ганц) | ✓ PDF ×2 |
| Бүрэн дунд боловсролын үнэмлэх | — | ✓ PDF |
| Төрсний бүртгэлийн лавлагаа | Хэнд: Өөртөө / Хүүхдийн (`subject`) | ✓ PDF (өөртөө); хүүхдийнх → «хүүхдийн регистрийн дугаар»* |
| Суралцаж байгаа тодорхойлолт | — | «бүртгэлгүй» (тухайн хүн суралцдаггүй) |
| Тэтгэврийн нэрийн дансны лавлагаа | — | ✓ PDF |
| Цэргийн алба хаасан лавлагаа (архив) | — | төлбөртэй, ажлын өдрөөр гардаг → автоматаар авахгүй |

\* Хүүхдийн регистрийн дугаарыг ХУР-ын хүүхдийн мэдээллээс бөглөдөг. Туршсан бүртгэлд хүүхэд бүртгэлгүй байсан тул энэ хэсгийг бодитоор туршаагүй.

«Жагсаалтаар» таб нь ижил collector-ийг ашигладаг. Нэгтгэсний дараа side panel-ийг (жагсаалт задлах, AI-гүй горим, сонголт, ZIP) chrome API-ийн mock дээр туршсан. Бодит e-Mongolia session дээр дахин туршаагүй.

«(гадаад хэлээр)» лавлагаа (2026-10-08): бодит туршилтад «маягтыг өөрөө бөглөнө (бөглөх: хэл сонгох)» гэж зогсож байсан. «Хэл сонгох»-ыг бөглөх кодыг бодит Ant Design 5-ын Select (нэг ба олон сонголттой), Radio, Checkbox дээр туршсан. Бодит e-Mongolia маягт дээр дахин шалгах шаардлагатай. Сонголт олдохгүй бол алдааны текстэд маягтын сонголтууд харагдана, жишээ нь «хэл сонгох (франц хэл, герман хэл)».

## Мэдээллийн эх сурвалж

Эдгээрийг e-Mongolia сайтын JS-ээс олсон. «Миний мэдээлэл» хэсэг ХУР-ын эдгээр сервисийг дууддаг. Жагсаалт нь [extension/sources.js](extension/sources.js)-д байна:

| Мэдээлэл | ХУР сервис | Параметр (`customFields`) |
|---|---|---|
| Эрүүл мэндийн даатгал | `WS300101_getInsuranceFee` | — |
| НДШ | `WS100501_getCitizenSalaryInfo` | `startYear` (өнгөрсөн он), `endYear` (энэ он), `reason` |
| Төлөгдөөгүй нэхэмжлэх | `WS100439_unpaidInvoiceInfo` | — |
| Зээл | `WS100831_citizenLoanInfo` | — |
| Тээврийн хэрэгсэл | `WS100406_getCitizenVehicleList` | — |
| Тээврийн хэрэгслийн торгууль | `WS100403_getVehiclePenaltyList` | машин бүрээр `plateNumber` |
| Тээврийн хэрэгслийн оношилгоо | `WS100409_getVehicleInspectionInfo` | машин бүрээр `cabinNumber` |
| Албан журмын даатгал | `WS100458_MandatoryInsuranceShortList` | — |
| Иргэний үнэмлэх | `WS100101_getCitizenIDCardInfo` | — |
| Гадаад паспорт | `WS100110_passportInfo` | — |
| Үл хөдлөх хөрөнгө | `WS100202_getPropertyList` | — |

Хүсэлтийн хэлбэр нь `POST /api/routes/xyp`:
- header: `X-Auth-Token: <auth-token cookie>`
- body: `{ "target": "xyp-data", "params": { "serviceCode": "...", "sid": null, "customFields": {...} } }`

Сайт өөрөө `customFields`-д `regnum` илгээдэг. Гэхдээ сервер үүнийг token-оос авдаг тул илгээх шаардлагагүй. Хариуны `resultCode: 1` нь «олдсонгүй», өөрөөр хэлбэл мэдээлэл бүртгэлгүй гэсэн утгатай. 2026-10-07-нд нэвтэрсэн session дээр шалгахад 11 эх сурвалж бүгд амжилттай ажилласан. Харин машин бүрээр дуудах хэсгийг машин бүртгэлгүй бүртгэл дээр бодитоор туршиж чадаагүй.

## AI сервис (worker/)

Төслийн эзэн AI сервисийг нэг удаа deploy хийнэ. Ингэснээр бүх хэрэглэгч эзний **нэг** key-ээр AI ашиглана.
```bash
cd worker
npm install
npx wrangler login                       # Cloudflare бүртгэл (үнэгүй)
npx wrangler secret put GEMINI_API_KEY   # aistudio.google.com-ийн key
npx wrangler deploy                      # → https://minii-medeelel-ai.<нэр>.workers.dev
```
Гарсан URL-ийг [extension/config.js](extension/config.js)-ийн `SERVICE_URL`-д бичээд push хийнэ.

Нэгтгэсэн `worker/`-ийг 2026-10-09-нд deploy хийж, 4 endpoint-ыг зохиомол өгөгдлөөр шалгасан:

| Endpoint | Үр дүн |
|---|---|
| `/parse` | 4 мөртэй жагсаалтыг 3 e-Mongolia лавлагаа + 1 өөрөө бэлдэх зүйл болгон задалсан (37 сек, нөөц загвар руу шилжсэн) |
| `/plan` | Солонгосын визэд `language: англи`, `addresseeForeign: Embassy of the Republic of Korea in Mongolia` |
| `/summarize`, `/chat` | ✓ (2–6 сек) |

AI сервис ажиллахгүй үед «Жагсаалтаар» таб жагсаалтыг түлхүүр үгээр задална. Энэ горимд зураг уншихгүй.

- Байршил: Gemini API зарим бүсэд (жишээ нь Hong Kong) дэмжигддэггүй. Тиймээс `wrangler.toml`-д `[placement] region = "gcp:us-central1"` тохиргоогоор Worker-ийг АНУ-д ажиллуулдаг.
- Тогтвортой байдал: нэг загвар 35 секундэд хариу өгөхгүй, завгүй эсвэл хязгаарт хүрсэн бол дараагийн үнэгүй загвар руу шилжинэ (`worker/src/ai.js`-ийн `GEMINI_MODELS`).
- Хамгаалалт: extension-д нууц хадгалах боломжгүй тул IP тус бүрт минутад 10 хүсэлт, зөвхөн `chrome-extension://` origin-д CORS, 200KB-аас (жагсаалтын зурагт 1.5MB-аас) том өгөгдөл хүлээж авахгүй, мэдээллийг хадгалахгүй.

**Бусдад тараахаас өмнө:**
- Gemini-ийн үнэгүй хязгаар нэг key-д ногддог тул бүх хэрэглэгч түүнийг хуваалцана. Хэрэглэгч олон болбол «хязгаарт хүрлээ» алдаа гарна.
- Үнэгүй хувилбарт Google мэдээллийг бүтээгдэхүүнээ сайжруулахад ашигладаг. **Бусдын** хувийн мэдээлэл дамжих тул Gemini-ийн төлбөртэй хувилбар руу шилжих хэрэгтэй.
- Та бусдын хувийн мэдээллийг боловсруулж байгаа тул Хүний хувийн мэдээлэл хамгаалах тухай хуулийн дагуу хэрэглэгчээс зөвшөөрөл авч, нууцлалын бодлого гаргах шаардлагатай.

## Нууцлал

- Нууц үг, ДАН код extension-д огт орохгүй. Хэрэглэгч өөрөө нэвтэрнэ.
- Өгөгдлийг хэрэглэгчийн компьютер дээр **нууцалсны дараа** хадгална. Хадгалахаас өмнө РД, нэр, хаяг, утас, имэйл, зураг, карт болон дансны дугаарыг хасна.
- AI руу зөвхөн «Шинжлэх» дарах эсвэл асуулт илгээх үед нууцалсан мэдээлэл явна. Юу илгээгдсэнийг «Дэлгэрэнгүй»-ээс харж болно.
- Нууцалсан ч торгуулийн дүн, даатгалын төлөв, зээлийн үлдэгдэл мэт **хувийн санхүүгийн мэдээлэл AI руу очно**. Бүтээгдэхүүн болгохдоо хэрэглэгчээс тодорхой зөвшөөрөл авах хэрэгтэй.
- «Жагсаалтаар» табд AI руу зөвхөн жагсаалтын текст (эсвэл зураг) болон үйлчилгээний нэрс очно. Регистр, хаяг, PDF-ийн агуулга AI руу очихгүй. Жагсаалтын зурагт хувийн мэдээлэл бичигдсэн бол илгээхээс өмнө тайрч авна уу.
- Төлбөртэй, хүсэлт илгээдэг үйлчилгээг автоматаар эхлүүлэхгүй. «Илгээх», «Төлөх» товчийг хэзээ ч дарахгүй.
- ХУР-ын сервис бүрийг дуудах үйлдэл иргэний «мэдээлэл хандалтын түүх»-д бүртгэгдэж болно. Иргэн өөрөө өөрийн мэдээлэлд хандаж байгаа тул энэ нь хэвийн.

## Эрсдэл

- e-Mongolia-ийн UI өөрчлөгдвөл эвдэрнэ. Товчийг CSS-ээр биш текстээр хайдаг тул бага зэргийн өөрчлөлтөд тэсвэртэй.
- Бүтээгдэхүүн болгохоос өмнө автоматжуулалт үйлчилгээний нөхцөлтэй нийцэх эсэхийг И-Монгол академиас тодруулах хэрэгтэй. Урт хугацаанд албан ёсны зам нь ДАН OAuth + ХУР.
