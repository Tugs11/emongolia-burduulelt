# Бүрдүүлэлт AI — e-Mongolia PoC

Хэрэглэгч өөрийн Chrome дээр e-Mongolia-д нэвтэрнэ. Дараа нь бүрдүүлэх жагсаалтаа текст эсвэл зургаар оруулна.

Extension жагсаалтын мөр бүрийг дарааллаар нь боловсруулна:

**жагсаалт задлах → e-Mongolia-ийн үйлчилгээний каталогтой тааруулах → үйлчилгээний хуудас (шууд path) → «Үйлчилгээ авах» → PDF татах**

Бүх PDF `Downloads/Burduulelt/` хавтаст дугаарлагдаж хадгалагдана, жишээ нь `01_Иргэний_үнэмлэхний_лавлагаа_2026-10-06.pdf`. Хэрэглэгч тэндээс нээж хэвлэх эсвэл хуваалцана.

## Нэг мөрийн урсгал

| Алхам | Хэн хийх | Тайлбар |
|---|---|---|
| 1. Жагсаалт задлах | AI (`/parse`) | «Иргэний үнэмлэхний хуулбар» гэсэн мөрийг «Иргэний үнэмлэхний лавлагаа» гэсэн хайлтын нэр болгоно. «Цээж зураг» мэт e-Mongolia-д байхгүй зүйлийг «өөрөө бэлдэнэ» гэж тэмдэглэнэ. |
| 2. Тааруулах | `services.js` | `content/search?pageSize=5000&query=` API-аас бүх SERVICE-ийг (~1460) татаж, 24 цаг кэшлэнэ. Дагавар үл хамаарсан үг тааруулалт + trigram ижил төстэй байдлаар эрэмбэлнэ. Сайтын хайлт бүтэн үгээр AND хийдэг тул («үнэмлэхний» → 0) ашиглахгүй. |
| 3. Сонгох | AI (`/pick`) эсвэл хэрэглэгч | Итгэлтэй бол автоматаар сонгоно. Үгүй бол шилдэг 6-г харуулж хэрэглэгчээр сонгуулна, сонголтыг `learned`-д санана. AI горимд шилдэг 6-ийн **нэрсийг л** AI руу илгээнэ. |
| 4. Аюулгүй байдлын шалгалт | content script | «Төлбөр: Үнэгүй», «Хугацаа: Шууд» биш бол автоматаар үргэлжлүүлэхгүй. Хэрэглэгчид «Хуудсыг нээх» товч санал болгоно. |
| 5. Татах | content + background | Үндсэн хэсгийн «Үйлчилгээ авах» товчийг дарна. Цэсэнд мөн ижил нэртэй, `/service` руу хөтөлдөг товч байгаа тул `nav/aside/header` доторхыг алгасна. Шууд гардаг лавлагаа `/service/{id}/apply` хуудсанд **blob: iframe**-д PDF-ээр гардаг. Content script blob-ийг уншиж (`%PDF-` эсэхийг шалгаад) data URL болгон background руу дамжуулна. Background `chrome.downloads`-аар хадгална. Нэмэлт маягт эсвэл modal гарвал зогсоож хэрэглэгчид хуудсыг нээж өгнө. |

AI-гүй горим (Worker URL хоосон үед) `services.js`-ийн `HINTS` болон энгийн текст тааруулалтаар ажиллана. Энэ горим зураг уншихгүй.

## Нууцлал, аюулгүй байдал

- Нууц үг, ДАН код авахгүй. Хэрэглэгч өөрөө нэвтэрнэ.
- AI руу зөвхөн **жагсаалт ба үйлчилгээний нэрс** очно. Регистр, хаяг, PDF-ийн агуулга огт очихгүй.
- Төлбөртэй, хүсэлт илгээдэг үйлчилгээг автоматаар эхлүүлэхгүй. «Илгээх», «Төлөх» товчийг хэзээ ч дарахгүй. «Хадгалах» нь хуудасны bookmark тул бас дарахгүй.

## Бүтэц

```
extension/
  manifest.json
  services.js    HINTS (түгээмэл нэр → албан ёсны нэр), AI-гүй задлах/сонгох
  services.js    … мөн каталог татах, rankCatalog / confidentPick
  content.js     нэвтэрсэн эсэх, үйлчилгээний мэдээлэл унших, товч дарах
  background.js  урсгалыг удирдах, PDF барих, нэр өгөх
  sidepanel.*    UI
worker/          /parse, /pick (Claude Haiku 4.5)
```

## Ажиллуулах

1. Worker:
   ```bash
   cd worker
   npx wrangler secret put ANTHROPIC_API_KEY
   npx wrangler deploy
   ```
2. Chrome-оос `chrome://extensions` руу орж Developer mode-ыг асаана. *Load unpacked* дарж `extension/` хавтсыг сонгоно.
3. Extension-ий дүрс дээр дарж side panel-ийг нээнэ. Тохиргоо хэсэгт Worker URL-ээ оруулна.
4. «e-Mongolia нээх» дарж ДАН-аар нэвтэрнэ.
5. Жагсаалтаа оруулаад «AI-аар шинжлэх» → «Бүгдийг дарааллаар нь татах» дарна.

Хайх нэр буруу гарвал мөр бүрийн «хайх:» талбарыг гараар засаад «Дахин оролдох» дарна.

## Эрсдэл

- e-Mongolia-ийн UI өөрчлөгдвөл эвдэрнэ. Товчийг CSS-ээр биш текстээр хайдаг тул бага зэргийн өөрчлөлтөд тэсвэртэй.
- Бүтээгдэхүүн болгохоос өмнө автоматжуулалт үйлчилгээний нөхцөлтэй нийцэх эсэхийг И-Монгол академиас тодруулах хэрэгтэй. Урт хугацаанд албан ёсны зам нь ДАН OAuth + ХУР.
